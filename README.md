## 在做的事

**技能库收敛**
把散落在多个工具目录下的技能合并成单一真源。难点不在复制文件，在于 Windows junction 的透明性——任何工具清空自己的 skills 目录，真源就被清空。

**知识库作为 Agent 的上下文**
笔记不是写给人看的，是写给未来 Agent 检索的。每条笔记自带摘要、来源、置信度，让一个没有上下文的 Agent 能在 10 秒内判断相关性。

**从 0 验证**
不接单、不做能力军备竞赛。先做出能定价的东西，再谈其他。
